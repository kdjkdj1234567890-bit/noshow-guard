# 🛡️ 노쇼 가드 — 예약 전날/당일 자동 확인 문자

**타겟 고객**: 동네 사장님들 (청소·미용실·이사·인테리어 업체 등 예약제로 운영하는 가게).
개발자가 아니라, **돈을 쓰는 사장님**이 고객입니다. 화면의 모든 문구는 사장님 말로 썼고,
개발자 용어는 하나도 없습니다.

## 왜 만들었는가

높은 가치는 느끼는 사람들에게 전달되어야 합니다.

동네 사장님들은 매일 새벽같이 일어나 가게 문을 엽니다. 그런데 정작 사장님의
시간과 정성은 아무도 세어주지 않았습니다. 노쇼 한 건에 버려지는 건 돈이 아니라,
미리 준비한 사장님의 시간입니다.

노쇼 가드는 그 시간을 지켜주는 것에서 시작했습니다. 확인 문자 한 통이
사장님의 저녁을 편하게 만들고("빈 시간 때문에 속상해하지 마세요"),
빈 시간이 줄어드는 게 사장님의 자존감이 되기를 바랍니다.

여기에 쌓인 예약 기록과 단골 명단은 사장님의 재산입니다.
**이 데이터는 10년 후에도 사장님의 것입니다.**
자녀분이나 믿는 직원에게 가게를 물려주실 때("가게 이어받기"),
사장님이 쌓은 신뢰가 그대로 이어지도록 만듭니다.

우리는 사장님의 일을 세상이 알아주게 만듭니다.

## 실행 방법

```bash
bash run.sh
```

- 기본 주소: **http://localhost:5009**
- 5009번 포트가 이미 사용 중이면 5010, 5011… 순서로 자동 전환됩니다.
  (실행 시 터미널에 표시되는 주소를 확인하세요)
- 처음 실행하면 데모용 예약 데이터가 자동으로 들어갑니다.
- 종료: `Ctrl+C`
- 기술: Python Flask + SQLite. 외부 API·유료 서비스 없이 전부 동작합니다.

## 핵심 어필 포인트 (사장님 설득용)

1. **업종별 특화 버전** — 첫 화면에서 "어떤 가게세요?"를 고르면
   청소업체 / 미용실·네일샵 / 이사·용달에 맞게 서비스 메뉴와 문자 내용이 바뀝니다.
   - 청소업체: 입주청소·정기청소 메뉴 + "청소 전날 준비물 안내" 문자
   - 미용실·네일샵: 시술 메뉴 + 담당 디자이너명 포함 "내일 ○○시 예약 확인" 문자
   - 이사·용달: 이사 메뉴 + "이사 당일 체크리스트" 문자
2. **첫 화면 수익 시뮬레이터** — 월 예약 수·평균 단가 두 개만 입력하면
   "노쇼 30% → 5%로 줄면 월 ○○만원 추가 수익"이 바로 계산됩니다.
   숫자로 설득하는 데모의 시작점입니다.
2. **자동 알림** — 예약 전날 + 당일 아침에 확인 문자가 자동으로 나갑니다.
   사장님은 버튼 한 번만 누르면 됩니다. (데모에서는 실제 문자 발송 없이 시뮬레이션)
3. **손님은 버튼 하나** — 문자 속 링크를 누르면 '확정할게요 / 시간 변경 / 취소'
   세 가지 중 하나만 고르면 됩니다. 전화 받을 필요가 없습니다.
4. **시간 변경 중복 체크** — 손님이 직접 시간을 바꿔도 이미 찬 시간은
   자동으로 걸러집니다. 빈 시간이 생기면 그 자리도 다시 채울 수 있습니다.
5. **사장님 현황판** — 오늘 예약 현황(확정/응답 대기/변경/취소),
   이번 달 노쇼율 추이, 그리고 **"알림 덕분에 지킨 예약 N건, ○○만원"**을
   보여줍니다. 효과가 돈으로 보입니다.
6. **노쇼 블랙리스트** — 오지 않은 손님은 '노쇼 등록' 한 번으로
   블랙리스트에 기록·관리됩니다.

## 화면 구성

| 주소 | 화면 |
|---|---|
| `/` | 짜증 오프닝 + 업종 선택 + 수익 시뮬레이터 (첫 화면) |
| `/briefing` | 사장님 오늘 브리핑 — 오늘 예약·벤치마크·존엄 메시지·루틴 인사 |
| `/register` | 예약 등록 |
| `/reservations` | 예약 목록 |
| `/reminders` | 자동 알림 센터 (발송 + 발송 이력) |
| `/r/토큰` | 손님이 받는 확인 화면 (문자 속 링크) |
| `/dashboard` | 사장님 현황판 |
| `/blacklist` | 노쇼 블랙리스트 |
| `/value` | 가치 계산기 + 경쟁사 비교표 + ROI ("월 3만원으로 월 ○○만원 지키세요") |
| `/report` | 월간 리포트 ("이번 달 벌어다준 돈") + 단톡방 공유 |
| `/growth` | 옆 가게 소개 리워드 + FOMO + 성장 시뮬레이터 |
| `/about` | 소개 — 레거시 철학 + 일곱 가지 약속 + 사명 선언문 |
| `/badge` | 입소문 배지 ("이 가게는 노쇼 가드 시스템을 사용합니다") |

## 사장님 심리 설계

- **짜증 모먼트 오프닝**: 첫 화면은 "어제 노쇼 2건. 준비한 시간 4시간이 버려졌습니다."로 시작 → "이제는 이렇게"
- **감정적 해방**: "빈 시간 때문에 속상해하지 마세요"
- **도파민 대시보드** (`/briefing`): 오늘 예약 N건, 이번 달 성적, 새 예약 시 "새 손님이 왔어요! 🎉" 축하
- **벤치마크**: "우리 동네 청소업체 평균 노쇼율 18%, 사장님은 ○%" 비교 막대
- **쓰나미 모먼트**: "오늘 노쇼 0건이에요. 어제 준비한 시간이 헛되지 않았어요."
- **매일 루틴**: 아침 "오늘도 힘내세요 😊" / 저녁 "오늘 수고하셨어요" / 월말 "사장님 최고예요"
- **존엄**: "오늘 5가정이 사장님 덕분에 깨끗해졌어요" — 돈이 아니라 사람을 셉니다
- **정직**: 숫자를 부풀리지 않습니다. 노쇼가 있는 날엔 "0건"이라고 하지 않습니다

## 데모 시나리오 (3분)

1. `/` 에서 "어떤 가게세요?" 업종 선택 → 월 예약 수·평균 단가를 넣어 "되찾는 돈" 확인
2. `/register` 에서 내일 날짜로 예약 1건 등록 (미용실이면 디자이너명도 입력)
3. `/reminders` 에서 '전날 알림 보내기' → 발송 이력의 문자 미리보기 확인 (업종별 톤 확인)
4. '손님이 받는 화면 보기' → **확정할게요** 클릭
5. `/dashboard` 에서 "알림이 지켜낸 돈" 금액이 올라간 것 확인

## 시리즈

"놓치고 있던 돈을 찾아주는 시스템" 시리즈 중 3번입니다.
